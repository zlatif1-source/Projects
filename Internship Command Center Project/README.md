# Internship Command Center

A full-stack internship application tracker designed as a resume-ready project. It includes a Node.js backend API, persistent local data storage, filtering, analytics, application notes, deadlines, and a responsive frontend.

## Features

- Add, edit, and delete internship applications
- Track status from wishlist through offer
- Filter by status, priority, and search text
- See analytics for total, active, interview, and upcoming deadline counts
- Store notes, posting links, location, deadline, and applied date
- Persist data in `data/applications.json`

## Run Locally

```bash
npm start
```

Open `http://localhost:3000`.
